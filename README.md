# Nitin Arya - UI/UX Design System & Portfolio Showcase

A showcase portfolio demonstrating end-to-end UI/UX product design methodologies, case studies, and a scalable web design system. Created to demonstrate the intersection of B.Tech computer science engineering and enterprise product design.

## Features
- **Design System Architecture:** Scalable Vanilla CSS leveraging semantic CSS variables for colors, typography, margins, and layouts.
- **Responsive & Semantic Code:** Perfectly engineered for cross-device responsiveness (mobile-first), ensuring 100% technical feasibility of visual designs.
- **UI/UX Case Studies:** Details UX methodologies for:
  - *BharatYatri Stay*: Mobile-first user flows, accessibility for regional markets, and custom spacing.
  - *Dean RGIA MNNIT Dashboard*: Complex data tables, information architecture, and structured layouts.

## Tools Showcased
- **Design:** Figma, Framer, Sketch, Adobe Creative Suite, Canva
- **Front-End Feasibility:** HTML5, CSS3, JavaScript, Bootstrap
- **Processes:** Agile/Scrum, Usability Testing, Interactive Prototyping
